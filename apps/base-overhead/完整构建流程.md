# 项目构建流程
## 读取配置文件kraft.yaml文件
kraft configure

## 下载与构建
make prepare && kraft -v build --no-progress --fast --compartmentalize
这段时间内会将flexos_gate()和flexos_gate_r()进行实例化成flexos_nop_gate()和flexos_nop_gate_r(), 这个flexos_nop_gate代表同隔间内不同的lib之间的函数调用。因此我们的重点在于修改flexos_nop_gate为fabric_gate.

对于flexos_nop_gate中用到的函数所对应的lib，需要进行注册到fabric中，只用注册这个lib用到的函数（或者注册这个lib全部的函数）。所以我们需要扫描所有的flexos_nop_gate。

我们需要通过cocci工具修改的是跨fabric的调用，其余则不变。这个我在rule_fabric_gate.cocci.in中写到了

不过在这个期间不需要完成替换，我希望在这`make prepare && kraft -v build --no-progress --fast --compartmentalize`之后运行我们的脚本，完成替换与注册，注册代码等等放到apps/xxx/helper/中, 我之前的做法是写一个sh脚本(你可以借鉴改进，也可以使用更好的方法)：
```bash
#!/bin/sh
set -eu

if [ "$#" -ne 1 ]; then
	echo "usage: $0 <app-dir>" >&2
	exit 1
fi

SCRIPT_DIR=$(CDPATH= cd -- "$(dirname -- "$0")" && pwd)
REPO_ROOT=$(CDPATH= cd -- "$SCRIPT_DIR/../.." && pwd)
APP_DIR=$1

case "$APP_DIR" in
	/*) ;;
	*) APP_DIR="$REPO_ROOT/$APP_DIR" ;;
esac

if [ ! -d "$APP_DIR" ]; then
	echo "[fabric-build] missing app dir: $APP_DIR" >&2
	exit 1
fi

LIB_PATHS=$(python3 - "$APP_DIR/kraft.yaml" "$REPO_ROOT/libs" <<'PY'
from pathlib import Path
import sys

try:
	import yaml
except ImportError:
	yaml = None

kraft_yaml = Path(sys.argv[1])
libs_root = Path(sys.argv[2])
text = kraft_yaml.read_text(encoding="utf-8")

if yaml is not None:
	data = yaml.safe_load(text) or {}
	names = list((data.get("libraries") or {}).keys())
else:
	names = []
	in_libraries = False
	for raw in text.splitlines():
		if not raw.strip() or raw.lstrip().startswith("#"):
			continue
		if raw.startswith("libraries:"):
			in_libraries = True
			continue
		if in_libraries and not raw.startswith("  "):
			break
		if in_libraries and raw.startswith("  ") and raw.endswith(":"):
			names.append(raw.strip()[:-1])

paths = [str((libs_root / name).resolve()) for name in names if (libs_root / name).exists()]
print(":".join(paths))
PY
)

echo "[fabric-build] restoring rewritten gate call sites"
python3 "$SCRIPT_DIR/restore_fabric_sources.py" "$APP_DIR"

echo "[fabric-build] clearing per-app prepare marker"
rm -f "$APP_DIR/helper/.fabric-prepared"

echo "[fabric-build] cleaning old build outputs"
(cd "$APP_DIR" && kraft clean >/dev/null 2>&1 || true)

echo "[fabric-build] running make prepare"
(cd "$APP_DIR" && make prepare)

echo "[fabric-build] first pass: instantiate FlexOS gates"
(cd "$APP_DIR" && kraft -v build --no-progress --fast --compartmentalize)

echo "[fabric-build] restore legacy fabric_gate calls after instantiation"
python3 "$SCRIPT_DIR/restore_fabric_sources.py" "$APP_DIR"

echo "[fabric-build] regenerate helper files from instantiated sources"
python3 "$SCRIPT_DIR/gen_fabric_init.py" \
	--app-dir "$APP_DIR" \
	--out-dir "$APP_DIR/helper" \
	--lib-root "$REPO_ROOT/unikraft/lib" \
	--ext-lib-root "$REPO_ROOT/libs"

echo "[fabric-build] apply post-instantiation fabric gate rewrites"
sh "$APP_DIR/helper/apply_fabric_rules.sh"

echo "[fabric-build] second pass: rebuild with fabric_gate rewrites"
if [ -n "$LIB_PATHS" ]; then
	make -C "$REPO_ROOT/unikraft" A="$APP_DIR" L="$LIB_PATHS" -j4
else
	make -C "$REPO_ROOT/unikraft" A="$APP_DIR" -j4
fi
```


## 运行
kraft run
